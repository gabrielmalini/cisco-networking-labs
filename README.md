# Cisco Packet Tracer Networking Labs

Three network designs built and tested in **Cisco Packet Tracer**, from a small office LAN to a multi-site network with dynamic routing. Each lab includes the `.pkt` file, so you can open it and explore the configuration.

> University coursework: *Computer Systems* and *Computing Infrastructure*, BSc (Hons) Computing at Regent College London.

| Lab | Topics |
|---|---|
| [01 · Small office network](01-small-office-network) | Star topology, static IPs, DHCP, DNS, HTTP and email servers |
| [02 · Branch network with VLANs and VoIP](02-vlan-voip-branch-network) | VLANs, subnetting, inter-VLAN routing (router-on-a-stick), DHCP pools, IP telephony |
| [03 · Multi-site network with OSPF](03-multi-site-ospf-network) | HQ + remote branch, serial WAN link, OSPF dynamic routing, connectivity testing |

**Skills:** IPv4 addressing and subnetting · VLANs and trunking (802.1Q) · DHCP · DNS · OSPF · Cisco IOS CLI · network troubleshooting with `ping` and `show ip route`

## How to open

1. Install [Cisco Packet Tracer](https://www.netacad.com/cisco-packet-tracer) (free with a Cisco Networking Academy account).
2. Open the `.pkt` file inside each lab folder.
